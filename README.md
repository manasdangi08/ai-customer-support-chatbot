# 💬 AI Customer Support Chatbot

An intelligent, context-aware Customer Support Chatbot built with **Python**, **Streamlit**, and **Google Gemini API**. It answers customer inquiries regarding products, pricing, shipping, and store policies using a customizable knowledge base.

## 🚀 Features
- **Custom Knowledge Base (`knowledge_base.txt`):** Easily update store products, prices, and FAQs without changing code.
- **Context-Aware Conversations:** Remembers chat history for natural follow-up questions.
- **Multilingual Support:** Understands and replies in both English and Hinglish.

## 🛠️ Tech Stack
- **Language:** Python 3.9+
- **Frontend UI:** Streamlit
- **LLM Engine:** Google Gemini (`gemini-2.5-flash`)
